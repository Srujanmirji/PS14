# apps/web — SPEC

**Track:** Frontend · **Owner:** Frontend lead · **Priority:** P0

The React PWA. The same production build is wrapped by Capacitor into the Android app.

## Responsibilities

- Every screen in `docs/06-ux-flows-and-screens.md`.
- Runs `@yojana/engine` on device against the cached scheme bundle.
- Calls `apps/api` only for: scheme bundle refresh, extract, explain, stt, tts, feedback.
- Stores profile and app state locally (Dexie). Never talks to the database directly.

## Structure

```
apps/web/
├── index.html
├── vite.config.ts            # react, tailwind, pwa plugins; @ alias
├── capacitor.config.ts
├── public/
│   ├── schemes.bundle.json   # offline snapshot (generated by pnpm db:export)
│   ├── icons/
│   └── demo/                 # cached TTS audio + explanations for demo mode
└── src/
    ├── main.tsx
    ├── app/                  # SPEC.md
    ├── shared/               # SPEC.md

```
